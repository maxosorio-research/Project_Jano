# Changelog

Notable changes to Jano are recorded here.

## 0.1.0-rc.0 — 2026-09-20

### Included

- Portable local projects and stable document identities.
- Continuous original-PDF and generated-translation readers.
- User-initiated native extraction with conditional bundled English OCR.
- Local Ollama translation and review with protected structural content.
- Deterministic segment-ID alignment, synchronized semantic scrolling, and
  bilingual selection projection.
- A reproducible real-PDF synchronization fixture and manual exit procedure.

### Scope decisions

- Jano 0.1 supports translations generated by Jano; external translation
  ingestion and heuristic alignment are deferred.
- Recoverable destructive deletion is planned as a project-local trash system.
- Hybrid storage is the accepted target: SQLite for structured mutable state,
  ordinary files for content/artifacts, and JSON only for bootstrap and exports.
- Trademark documentation is deferred to the final public release.
