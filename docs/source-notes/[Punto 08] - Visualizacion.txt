### Indicador de alineación

Tu idea de hacerlo aparecer al interactuar con el `.md` me parece mejor que tener permanentemente un panel enorme de alineación.

Cuando haces clic sobre un párrafo traducido:

```text id="g9bzcm"
TRADUCCIÓN

Las instituciones constituyen...
██████████████████████████
```

Jano identifica:

```text id="2qpnyh"
seg_es_184
    ↕
seg_en_181
```

y en el original podría aparecer una señal discreta:

```text id="3x5co2"
ORIGINAL

Institutions constitute...
░░░░░░░░░░░░░░░░░░░░░░
│
└─ alineado
```

Esto aprovecha exactamente la misma infraestructura que ya necesitamos para selección bilingüe: Jano distingue entre la selección real del usuario y la correspondencia proyectada en el otro documento. fileciteturn0file11L40-L58

Si quieres inspeccionar más, al hacer clic en un pequeño indicador podría abrirse temporalmente:

```text id="2b6emd"
Alineación

seg_en_181
↕
seg_es_184

Tipo: 1 → 1
Confianza: alta
```

Para un usuario normal eso permanecería oculto.

### Búsqueda

Aquí distinguiría dos comportamientos dentro del mismo buscador:

```text id="fky8a4"
⌕ institutions
```

Podría mostrar:

```text id="g8afdt"
Original      17 resultados
Traducción    19 resultados
```

y permitir:

```text id="a4tx1j"
[ Ambos ] [ Original ] [ Traducción ]
```

Con `Enter` y `Shift+Enter` para siguiente/anterior resultado.

Más adelante ese mismo buscador puede evolucionar a búsqueda sobre anotaciones y evidencias, pero para el lector inicial mantendría búsqueda textual convencional.

### Paleta

Mantendría la dirección visual que ya habíamos fijado: **teal como acento, no como fondo omnipresente**. La interfaz general debería apoyarse principalmente en carbón, azul grisáceo muy oscuro y blanco suave; el teal identifica selección, controles activos y foco. fileciteturn0file6L126-L159

Algo conceptualmente así:

```text id="9ieudi"
Fondo principal       azul petróleo casi negro
Panel secundario      carbón azulado
Texto principal       blanco cálido / gris muy claro
Texto secundario      gris azulado
Teal                  selección / foco / controles
Ámbar                 alineación / vínculo
Rojo apagado          errores / archivo faltante
```

Evitaría blanco puro `#FFFFFF` sobre negro puro `#000000`, porque durante varias horas de lectura genera demasiado contraste.

Y permitiría:

```text id="1xh482"

● Jano Dark
○ Jano Light
○ Sistema
○ Personalizado
```

aunque `Jano Dark` sería el predeterminado.

### Atajos

Conservaría todos los convencionales del sistema y añadiría muy pocos específicos de Jano:

| Acción | Windows/Linux | macOS |
|---|---|---|
| Buscar | `Ctrl+F` | `⌘F` |
| Copiar | `Ctrl+C` | `⌘C` |
| Seleccionar todo | `Ctrl+A` | `⌘A` |
| Abrir archivo/proyecto | `Ctrl+O` | `⌘O` |
| Configuración | `Ctrl+,` | `⌘,` |
| Mostrar/ocultar sidebar | `Ctrl+B` | `⌘B` |
| Alternar sincronización | `Ctrl+Shift+S` | `⌘⇧S` |
