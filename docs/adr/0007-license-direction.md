# ADR 0007 — Source-available non-commercial license direction

Status: Accepted for early versions; revisit reciprocity before 1.0.

## Decision

Use the official, unmodified PolyForm Noncommercial 1.0.0 license text for early public versions, with Jano brand/trademark handled separately.

## Consequences

- Do not describe Jano as OSI-approved open source.
- Prefer permissively licensed dependencies.
- Review copyleft/custom/source-available dependencies explicitly.
- Add the official license text only from the authoritative source before public distribution.
